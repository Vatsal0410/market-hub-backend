📚 API Docs

Auth Users Categories Products Cart Orders

API Documentation

Base URL: http://localhost:5000/api

🔐 Auth
POST /auth/register Public
Register a new user
{ "fname": "string", "lname": "string", "email": "string", "password": "string" }
POST /auth/login Public
Login user
{ "email": "string", "password": "string" }
POST /auth/forgot-password Public
Request password reset
{ "email": "string" }
POST /auth/verify-otp Public
Verify OTP for password reset
{ "email": "string", "otp": "string" }
POST /auth/reset-password Public
Reset password using reset token
{ "resetToken": "string", "newPassword": "string" }
GET /auth/profile User
Get current user profile
PUT /auth/profile User
Update user profile
{ "fname": "string", "lname": "string" }
PUT /auth/password User
Change password
{ "currentPassword": "string", "newPassword": "string" }
POST /auth/verify-email User
Verify email with OTP
{ "otp": "string" }
POST /auth/resend-verification User
Resend verification OTP
POST /auth/logout User
Logout user
👥 Users
GET /users Admin
Get all users (with pagination)
GET /users/:id Admin
Get user by ID
PUT /users/:id Admin
Update user
{ "fname": "string", "lname": "string", "role": "user|admin", "isEmailVerified": boolean }
DELETE /users/:id Admin
Delete user (soft delete)
PUT /users/:id/restore Admin
Restore deleted user
📁 Categories
GET /categories Public
Get all categories
GET /categories/:id Public
Get category by ID
POST /categories Admin
Create category
{ "name": "string", "description": "string", "image": "string", "parentCategory": "string" }
PUT /categories/:id Admin
Update category
DELETE /categories/:id Admin
Delete category (soft delete)
PUT /categories/:id/restore Admin
Restore deleted category
📦 Products
GET /products Public
Get all products (with filters)
GET /products/:id Public
Get product by ID
POST /products Admin
Create product
{ "name": "string", "description": "string", "price": number, "category": "string", "stock": number, "unit": "string", "images": string[] }
PUT /products/:id Admin
Update product
DELETE /products/:id Admin
Delete product (soft delete)
PUT /products/:id/restore Admin
Restore deleted product
🛒 Cart
GET /cart User
Get user's cart
POST /cart User
Add item to cart
{ "productId": "string", "quantity": number }
PUT /cart/:productId User
Update cart item quantity
{ "quantity": number }
DELETE /cart/:productId User
Remove item from cart
DELETE /cart User
Clear entire cart
GET /cart/all Admin
Get all carts
GET /cart/:id Admin
Get cart by ID
📋 Orders
GET /orders User
Get user's orders
POST /orders User
Create order from cart
{ "shippingAddress": { "street": "string", "city": "string", "pincode": "string" }, "paymentMethod": "string" }
GET /orders/:id User/Admin
Get order by ID (User gets own, Admin gets any)
PUT /orders/:id/status Admin
Update order status
{ "orderStatus": "processing|shipped|delivered|cancelled", "paymentStatus": "pending|paid|failed|refunded" }
PUT /orders/:id/payment-status Admin
Update payment status
PUT /orders/:id/cancel User
Cancel order
GET /orders/all Admin
Get all orders
DELETE /orders/:id Admin
Delete order (soft delete)
PUT /orders/:id/restore Admin
Restore deleted order

🔑 Authentication

Include token in header: Authorization: Bearer YOUR_TOKEN
